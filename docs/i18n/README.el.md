Η τεκμηρίωση για build, αρχιτεκτονική και δοκιμές υπάρχει μόνο στα αγγλικά. Τα στιγμιότυπα οθόνης προέρχονται από την ισπανική πύλη της BMW· οι ονομασίες και η διάταξη στη χώρα σας μπορεί να διαφέρουν. Η διεπαφή στο ρολόι είναι στα αγγλικά.

Ένα **widget** Garmin που εμφανίζει στο ρολόι σας την τρέχουσα κατάσταση της BMW σας — αυτονομία, καύσιμο, κλείδωμα, πόρτες/παράθυρα, ελαστικά, οδόμετρο και πληροφορίες σέρβις — απευθείας από το επίσημο REST API [BMW CarData](https://bmw-cardata.bmwgroup.com/customer/public/api-specification).

> Προσωπικό project χόμπι. Δεν σχετίζεται με τη BMW ή τη Garmin ούτε έχει εγκριθεί ή υποστηρίζεται από αυτές.

## Λειτουργίες

- **Glance** — κατάσταση κλειδώματος, αυτονομία και καύσιμο με μια ματιά στο καρουζέλ των widget.
- **Αυτονομία & καύσιμο** — υπολειπόμενη αυτονομία, καύσιμο σε %, λίτρα στο ρεζερβουάρ / μέχρι το γέμισμα και προαιρετική εκτίμηση κατανάλωσης (`~L/100 km`). Ηλεκτρικά και plug-in υβριδικά: μπαταρία σε % και ηλεκτρική αυτονομία.
- **Κλείδωμα** — SECURED / UNLOCKED, μια τελεία για κάθε ανοιχτή πόρτα (εμπρός + πίσω), το καπό και το πορτμπαγκάζ, καθώς και κόκκινο σήμα **W** όταν είναι ανοιχτό κάποιο παράθυρο. Εμφανής ένδειξη της ηλικίας των δεδομένων.
- **Οδόμετρο** — χιλιόμετρα και απόσταση μέχρι το επόμενο σέρβις (με προαιρετική δική σας τιμή).
- **Ελαστικά** — πίεση ανά τροχό σε σχέση με την πίεση-στόχο και εκτίμηση φθοράς των ελαστικών (το START εναλλάσσει τις τρεις προβολές).
- **Θέση αυτοκινήτου** — το σταθμευμένο αυτοκίνητό σας στον ενσωματωμένο χάρτη του ρολογιού· το START ενεργοποιεί ή απενεργοποιεί μια προβολή με zoom που μπορείτε να μετακινήσετε. Μόνο σε συσκευές με χάρτες (όλες οι υποστηριζόμενες εκτός από Forerunner 255, 255 Music, 265 και 745).
- **About car** — ομαδοποιημένη προβολή μόνο για ανάγνωση με τα σταθερά στοιχεία του οχήματος και ζωντανή τηλεματική (μπαταρία 12 V, ψυκτικό υγρό, θέση, Teleservice, …).
- **Ρυθμίσεις στο ρολόι** — λειτουργία ανανέωσης, χωρητικότητα ρεζερβουάρ, δική σας τιμή για το επόμενο σέρβις, εκτίμηση κατανάλωσης και το υπομενού **Manage** (επανασύζευξη / αποσύνδεση / διαγραφή όλων των containers).

## Υποστηριζόμενες συσκευές

Ρολόγια Garmin fēnix, epix, Enduro, MARQ και Forerunner. Η τρέχουσα λίστα — και ποιες συσκευές δεν υποστηρίζονται — βρίσκεται στο [αγγλικό README](../../README.md#supported-devices).

## Ρύθμιση

Χρειάζεστε ένα **Client ID του BMW CarData** (δωρεάν, δημιουργείται στην πύλη BMW CarData) και λογαριασμό My BMW σε χώρα όπου προσφέρεται το CarData (ΕΕ / Ηνωμένο Βασίλειο). Όλα τα υπόλοιπα γίνονται αυτόματα: το ρολόι βρίσκει το VIN σας και δημιουργεί μόνο του τα containers δεδομένων του.

### 1. Δημιουργία client BMW CarData

Μία φορά, περίπου 10 λεπτά. Οι ονομασίες στην πύλη διαφέρουν ανά γλώσσα· εδώ δίνονται ως παράδειγμα οι ισπανικές — είναι και αυτές που φαίνονται στα στιγμιότυπα οθόνης.

1. Συνδεθείτε στην **πύλη web My BMW** της χώρας σας και ανοίξτε την επισκόπηση του οχήματος — π.χ. `https://www.bmw.es/es-es/mybmw/vehicle-overview`.
2. Ανοίξτε το **BMW CARDATA**.
3. Στην ενότητα τεχνικής πρόσβασης — *Technical access to BMW CarData* / ES *ACCESO TÉCNICO A BMW CARDATA* — **δημιουργήστε έναν client** και αντιγράψτε το **Client ID**.
4. Ενεργοποιήστε **και τους δύο** διακόπτες: *CarData API access* (ES *Solicitar acceso a la API de CarData*) και *CarData streaming* (ES *Transmisión de CarData*). Το widget ζητά και τις δύο άδειες μαζί κατά τη σύνδεση, επομένως πρέπει να είναι ενεργές και οι δύο, παρότι χρησιμοποιείται μόνο το REST API.

   ![Πύλη BMW CarData (ισπανικά): η σελίδα του client με το Client ID — καλυμμένο εδώ — και τους δύο διακόπτες ενεργοποιημένους](../images/cardata-client.png)

5. Στην ενότητα streaming ανοίξτε την **επιλογή δεδομένων** (ES *Cambiar selección de datos*) και επιλέξτε τα πεδία δεδομένων της ενότητας 2. Η επιλογή όλων λειτουργεί επίσης — το widget δεν ζητά ποτέ τίποτα εκτός αυτής της λίστας.

   ![Πύλη BMW CarData (ισπανικά): η κάρτα streaming με κατάσταση «ready» και το κουμπί «Cambiar selección de datos»](../images/cardata-streaming.png)

6. Αποθηκεύστε και **περιμένετε 5–10 λεπτά**: ένας client που μόλις δημιουργήθηκε δεν είναι άμεσα χρησιμοποιήσιμος.

### 2. Επιλογή των πεδίων δεδομένων

Είναι ακριβώς τα **41 πεδία δεδομένων** του «πλήρους» container του widget. Η λίστα (τεχνικά αναγνωριστικά, ίδια σε όλες τις γλώσσες) βρίσκεται στο αγγλικό README: [Select the data fields](../../README.md#2-select-the-data-fields).

![Πύλη BMW CarData (ισπανικά): η επιλογή δεδομένων οχήματος με τα 41 πεδία επιλεγμένα](../images/cardata-data-selection.png)

Συμβουλή: ενεργοποιήστε το φίλτρο που εμφανίζει μόνο τα επιλεγμένα χαρακτηριστικά (ES *Mostrar solo atributos seleccionados*) για να ελέγξετε την επιλογή σας.

### 3. Σύζευξη του ρολογιού

1. **Garmin Connect** → η συσκευή σας → *Connect IQ Apps* → **BMW Status** → *Settings* → επικολλήστε το **Client ID**. Αφήστε κενά τα VIN και Container ID.
2. Ανοίξτε το widget → **START to connect**. Εμφανίζονται ένας κωδικός σύζευξης και ένας σύνδεσμος.
3. Εγκρίνετε τον κωδικό στον σύνδεσμο που εμφανίζει το ρολόι (η BMW τον στέλνει μαζί με τον κωδικό· εναλλακτικά `customer.bmwgroup.com/oneid/#/link`), από κινητό ή υπολογιστή, συνδεόμενοι με τον λογαριασμό σας στη BMW.
4. Το ρολόι βρίσκει το VIN σας, δημιουργεί και τα δύο containers και κατεβάζει τα δεδομένα του αυτοκινήτου σας. Δεν χρειάζεται να πληκτρολογήσετε VIN ή containers. Το refresh token ισχύει περίπου 2 εβδομάδες και ανανεώνεται σε κάθε χρήση — ένα widget που ανοίγετε τακτικά παραμένει συζευγμένο.

### Ανανέωση

- **START** στη σελίδα *Range & Fuel* ή *Lock* → άμεση πλήρης ανανέωση (60 s αναμονή). Στη σελίδα *Tyres* το START εναλλάσσει πραγματική/στόχο/φθορά, στη σελίδα χάρτη εναλλάσσει το zoom, στο *Odometer* δεν κάνει τίποτα.
- **Μία φορά την ημέρα γύρω στις 10:00** — πλήρης λήψη δεδομένων ακόμη και σε χειροκίνητη λειτουργία· διατηρεί επίσης ενεργή τη σύνδεση (tokens).
- Το **Update Mode** (*Auto hourly* / *Auto adaptive*) υπάρχει μόνο σε συσκευές με **API 6.0+** — fēnix 8, 8 Pro, 8 Solar, fēnix 9 (όλες οι παραλλαγές), fēnix E, Enduro 3 / 4, MARQ Gen 3, FR970. Όλες οι άλλες συσκευές λειτουργούν χειροκίνητα + ημερησίως και η ρύθμιση είναι κρυφή.
- Η BMW επιτρέπει **περίπου 50 κλήσεις δεδομένων ανά 24 ώρες**. Μια πλήρης ανανέωση καταναλώνει 3, μια ερώτηση στο παρασκήνιο 1· η ανανέωση του token δεν προσμετράται.
- Η φρεσκάδα των δεδομένων εξαρτάται από το **αυτοκίνητο**, όχι από το widget: μια σταθμευμένη BMW μπορεί να στέλνει δεδομένα μόνο κάθε λίγες ώρες. Γι' αυτό οι σελίδες δείχνουν την ηλικία των δεδομένων.

### Αντιμετώπιση προβλημάτων

| Ένδειξη / σύμπτωμα | Αιτία / λύση |
|---|---|
| `BMW Widget` / `Add Client ID in the Garmin Connect app` | Δεν υπάρχει ακόμη Client ID στις ρυθμίσεις — βήμα 3.1. Τα κενά στην αρχή ή στο τέλος της επικολλημένης τιμής αγνοούνται. |
| `Auth failed` → `Client ID looks incomplete — copy it again…` | Η BMW απέρριψε τη σύζευξη και η αποθηκευμένη τιμή δεν είναι πλήρες Client ID 36 χαρακτήρων — συνήθως επικολλήθηκε μόνο το μισό. Αντιγράψτε το ξανά από την πύλη. |
| `Phone link lost — retrying…` κατά τη σύζευξη | Το ρολόι έχασε για λίγο τη σύνδεση με το Garmin Connect (συχνό όταν εγκρίνετε από το ίδιο κινητό). Ο κωδικός παραμένει έγκυρος· ολοκληρώστε την έγκριση — το ρολόι συνεχίζει μόνο του. |
| `No car on this BMW account` | Το BMW ID σας δεν έχει όχημα ή δεν είστε ο **κύριος** χρήστης του. Το CarData εξυπηρετεί μόνο τον κύριο χρήστη. |
| `Car not readable — check VIN` | Το VIN στις ρυθμίσεις είναι λάθος ή το αυτοκίνητο δεν βρίσκεται πια σε αυτόν τον λογαριασμό. Αδειάστε το πεδίο VIN για να το βρει μόνο του το widget. |
| `No car data yet` / `Check data selection in BMW portal` | Η λήψη πέτυχε αλλά δεν επέστρεψε τίποτα προς εμφάνιση: δεν έχουν επιλεγεί πεδία δεδομένων (βήμα 1.5) ή το αυτοκίνητο δεν έχει στείλει δεδομένα από τότε. |
| Η σύζευξη αποτυγχάνει αμέσως μετά τη δημιουργία του client | Η ενεργοποίηση 5–10 λεπτών στην πύλη δεν έχει ολοκληρωθεί ακόμη· δοκιμάστε ξανά. |
| `Re-auth needed` / `Press START to re-pair` | Το refresh token έχει λήξει (το widget δεν άνοιξε για περισσότερες από ~2 εβδομάδες) → **Manage → Re-pair**. |
| `Auth failed` → `Check CarData API + streaming are on in the BMW portal` | Ένας από τους δύο διακόπτες του client σας είναι απενεργοποιημένος στην πύλη (βήμα 1.4). Το widget ζητά και τις δύο άδειες με ένα αίτημα, οπότε η BMW απορρίπτει ολόκληρη τη σύζευξη. Ενεργοποιήστε τον ξανά, περιμένετε **5–10 λεπτά** και πατήστε ξανά START. |
| Σφάλμα container / `CU-124` | Η BMW επιτρέπει το πολύ **10 containers** ανά λογαριασμό. Η ρύθμιση προσφέρεται να τα διαγράψει όλα και να δοκιμάσει ξανά· διαφορετικά **Manage → Delete containers** (το widget δημιουργεί ξανά τα δικά του). |
| Λείπει μια σελίδα ή οι τιμές είναι κενές | Το αυτοκίνητό σας (ή η επιλογή σας στο CarData) δεν στέλνει αυτό το πεδίο — οι σελίδες κρύβονται αυτόματα όταν λείπουν τα βασικά τους δεδομένα. |

## Απόρρητο

Το widget διαβάζει τα δεδομένα του οχήματός σας μόνο για να τα εμφανίσει στο ρολόι σας· τίποτα δεν στέλνεται πουθενά εκτός από το ίδιο το API της BMW — δεν υπάρχει server πίσω από την εφαρμογή, ούτε analytics, ούτε SDK τρίτων. Πλήρης πολιτική (στα αγγλικά): [`PRIVACY.md`](../../PRIVACY.md).
